# /orchestrator learnings (written by /wrap-up, at most 12,000 characters)

- 2026-10-17: A session's checkout has no prod access: no `.env.local` there names the cloud deployment, so `npx convex … --prod` fails with "No CONVEX_DEPLOYMENT set", and the developer ruled that sessions run no prod command. Fix: the session wrote the files and handed each prod command, ready to paste with absolute paths, to the integrator, who holds the bound copy and confirmed each run; the branch's `state.json` was mirrored with `client-state.ts --dry-run`. Rule: a session runs no prod command; it hands each one to whoever holds the bound copy and mirrors the stage with `--dry-run`.
- 2026-10-17: The app's Prettier gate (`npm run format:check` in `app/`) does not reach `clients/` or `.claude/`. Fix: ran `npx prettier --check ../clients/<slug>` from `app/` and formatted every file but the transcript. Rule: format a client folder's files by hand from `app/`, never a transcript.
- 2026-10-17: In a fresh worktree there is no `clients-private/`, so `npm run check:privacy` checked email addresses only ("No clients-private/deny-list.txt"), and `app/node_modules` is missing. Fix: `npm ci` in `app/` first; each report said the privacy check ran emails-only. Rule: in a fresh worktree run `npm ci` before the gates and say when the privacy check ran without the deny list.
